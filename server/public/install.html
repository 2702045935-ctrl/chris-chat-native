把 CHRIS 聊天装到手机上

装完就是独立图标，点开全屏，和普通 App 一样

iPhone / iPad 添加到主屏幕

  1. 用 Safari 打开下面这个地址（一定要用 https 的）： https://192.168.2.7:5443/m.html
  2. 第一次会提示"此连接非私人连接"→ 点 显示详细信息 → 访问此网站（只有第一次要这样）
  3. 点屏幕底部中间的 分享 按钮（方框 + 向上箭头）
  4. 往下滑，选 添加到主屏幕 → 右上角 添加
  5. 回桌面就能看到绿色聊天图标，点开即是全屏 App

安卓 安装应用

  1. 用 Chrome 打开：https://192.168.2.7:5443/m.html
  2. 第一次提示证书不安全，点 高级 → 继续前往
  3. 点右上角 ⋮ → 安装应用 / 添加到主屏幕

说明

· 语音 / 视频通话必须用 https://192.168.2.7:5443 打开，浏览器只允许安全页面用麦克风和摄像头。
· 电脑版地址不变：http://192.168.2.7:5180/。
· 手机要和电脑连同一个 Wi-Fi。
